# claude-learning 🤖

Repositorio de aprendizaje estructurado para dominar el ecosistema Claude
(Anthropic) y obtener la certificación **CCA-F** (Claude Certified Architect –
Foundations).

## Objetivo
Construir conocimiento práctico desde los fundamentos hasta arquitecturas
agénticas, culminando en una aplicación propia funcional.

## Roadmap
| Mes | Fase | Foco |
|-----|------|------|
| 1 | Fundamentos | Claude Code, prompt engineering, Claude 101 |
| 2 | Construcción | Claude API desde Python, tools, manejo de errores |
| 3 | Agentes y MCP | Agentes multi-step, MCP servers, RAG básico |
| 4-5 | CCA-F | Preparación y certificación |

## Estructura
```
claude-learning/
├── mes-1-fundamentos/   # Prompts y ejercicios
├── mes-2-api/           # Scripts con la API
├── mes-3-agentes/       # Agentes y MCP
├── mes-4-5-ccaf/        # Prep certificación
└── app/                 # App propia
```

- Python · Snowflake · Google Sheets · Claude API
